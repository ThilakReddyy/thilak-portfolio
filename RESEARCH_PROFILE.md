## Flagship work: JNTUH Connect

### Product story

JNTUH Connect began as a 2022 Python/Django project that aggregated a student’s semester results, CGPA, credits, and backlogs. As usage grew, the system was redesigned around a Next.js frontend and a FastAPI backend with persistent storage, caching, asynchronous work queues, and production observability.

The project now has four visible product surfaces:

1. Web application
2. Backend/API platform
3. Native Android application
4. Native iOS application

### Publicly visible architecture

- Web: Next.js, React, TypeScript
- Backend: Python, FastAPI
- Persistence and caching: PostgreSQL, Redis
- Messaging: RabbitMQ
- Infrastructure: AWS EC2, Docker, Cloudflare
- Observability: Prometheus, Grafana, Loki
- Android: Kotlin, Jetpack Compose, Material 3, Hilt, Retrofit, Room, DataStore, Firebase Cloud Messaging
- iOS: Swift 6, SwiftUI, Swift Concurrency, Observation, URLSession, Codable, XcodeGen, Swift Testing, XCTest
